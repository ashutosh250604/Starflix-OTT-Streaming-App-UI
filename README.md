## ⭐ Overview
Starflix is a concept OTT streaming UI focused on clean design, easy navigation, and modern layout structure.

---

## 🧠 Design Intent
This project was built as a UI prototype to practice:
- Visual hierarchy  
- Component-based design  
- UX flows  
- Auto layout & variants  

You are welcome to explore, duplicate, or learn from it.

---

## 🎨 Key Screens
- Home  
- Movie Details  
- Search  
- Watchlist  
- Profile  

---

## 🛠 Tools Used
Figma, Auto Layout, Iconify, Component Variants
